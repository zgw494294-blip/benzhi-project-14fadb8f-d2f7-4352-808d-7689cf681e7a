# 舞台吊挂安全工作台

本项目为剧场技术团队提供单场演出的高空吊挂安全工作台，覆盖案卷建档、吊点与器材核验、载荷评估、负载彩排、整改复验、独立复核、证据冻结、开演放行凭据签发及验真。

工作台在同一案卷内支持带编辑租约、修订号和请求标识的吊点批量预检与原子提交；器材按吊点的主路径、冗余路径配装，以链路短板能力和演出时段内的证书有效性生成覆盖矩阵。正式评估前可创建不改变案卷状态的载荷试算，并逐点比较安全余量。

彩排按每个吊点生成位移、异响、制动和复位清单，测量项目保留全部重复测量并按最不利值判断。整改会生成器材复查、吊点观察和载荷复算的定向复验项；复核按不可变轮次保存证据清单、退回项和逐项响应。批准后签发的凭据可由演出技术负责人撤销，重新闭环后签发的替代凭据会关联前序凭据。

验真可按凭据标识区分格式错误、不存在、案卷不存在、已撤销、尚未生效、已过期、签名损坏、证据摘要不一致和有效状态。发生冻结差异时会定位变化的证据分区及其首个相关审计事件，冻结快照始终只读保留。

标准构建：`go build ./...`

启动服务：`go run ./cmd/server -addr=127.0.0.1:19091`

运行测试：`go test ./...`

竞态与静态检查：`go test -race ./...`、`go vet ./...`

启动并执行 HTTP 冒烟自检：`go run ./cmd/server -addr=127.0.0.1:19091 -db=:memory: -selfcheck`

服务默认监听高位回环端口，也可使用 `-addr=127.0.0.1:<port>` 或 `PORT` 环境变量配置。

浏览器打开服务根路径即可使用工作台。JSON 接口统一位于 `/api/cases/{caseId}` 下；案卷详情会返回吊点、配装覆盖、评估与试算、彩排进度、整改复验、复核轮次、凭据链和连续审计时间线。验真入口为 `/api/verify?credentialId=<credentialId>`。
